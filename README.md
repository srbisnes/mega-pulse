# Mega Pulse

**Protecting the Cold Chain with Real-Time IoT and AI on MegaETH.**  
*From Detection to Action in Seconds.*

> Mega Pulse no vende blockchain. Vende protección de inventario, reducción de pérdidas y continuidad operativa. La tecnología funciona como la capa invisible que garantiza velocidad, confianza y trazabilidad para las empresas.

## Visión

Convertir Mega Pulse en el estándar tecnológico para la gestión inteligente de la cadena de frío en Latinoamérica, proporcionando una infraestructura crítica capaz de reducir desperdicios, optimizar operaciones y garantizar la seguridad de productos sensibles mediante decisiones autónomas en tiempo real.

## Stack

- **Frontend**: React 18 + TypeScript + Vite + Tailwind CSS
- **Web3**: Wagmi + RainbowKit + Viem
- **Charts**: Recharts
- **Chain**: MegaETH (testnet placeholder) + Sepolia fallback

## Funcionalidades del MVP

- Dashboard en tiempo real con sensores IoT simulados
- Semáforo operacional (Normal / Riesgo moderado / Crítico)
- KPIs: Temperatura, Humedad, Sentimiento IA, Alertas, Inventario Protegido, ROI
- Inyección de anomalías (demo) → disparo de agentes autónomos
- Visualizador del smart contract `MegaPulseOracle.sol`
- Oráculo de sentimiento operacional
- Modelo SaaS (Starter / Business / Enterprise)
- Cumplimiento Ley 25.326 + Pitch para inversores

## Cómo correr localmente

```bash
npm install
npm run dev
```

Abre [http://localhost:5173](http://localhost:5173).
